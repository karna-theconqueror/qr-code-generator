Project Overview

A complete QR code generator with analytics dashboard. Features 7 QR types, custom styling, dynamic links, and real-time scan tracking with device/browser/OS detection. Built from scratch with zero external charting libraries.

QR Types Supported
  • URL — Website links, landing pages
  • Text — Plain text, codes, messages
  • Email — mailto: with subject/body
  • Phone — tel: links for click-to-call
  • SMS — Pre-filled text messages
  • WiFi — SSID + password for auto-connect
  • vCard — Contact cards with name, org, phone, email
